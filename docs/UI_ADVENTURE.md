# UI: from "website" to "adventure" – proposals (2026-11-24, not built yet except quick travel)

Done in 0.15: dock button 🗺 (map from anywhere, ⌂ = village while on the map; asks first inside a lesson or fight). Schriftwahl buttons are disabled where a script would give the answer away (writing steps lock 漢).

1. **Hotspot village** – the picture IS the menu: tap the shop door, tavern, notice board, gate. Button lists only for text choices.
2. **JRPG dialogue** – typewriter text, framed portrait, blinking ▼, choices as a cursor menu (▶ 店へ いく). Tap to skip.
3. **Pixel frames** – 9-slice frame around the scene and panels instead of rounded web cards; stats become a HUD (HP bar, coin, level badge) in the picture corner.
4. **Bottom dock as inventory belt** – icon slots (rune pouch, map, notebook, bag) instead of text buttons.
5. **Ambience** – time-of-day tint, lantern glow, drifting smoke/fireflies, 2-frame idle animations; instant screen changes (no cutscene wipes).
6. **Rewards you can see** – hanko seals for finished lessons, a rune scroll that fills, loot pop-ups with sprite.
