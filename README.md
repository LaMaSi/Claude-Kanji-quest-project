# 狼の村 – Wolfsdorf (Japanese learning RPG, German UI)

Static PWA at the repo root (no build step, no dependencies), deployed to GitHub Pages by `.github/workflows/pages.yml`.

Try locally: `python3 -m http.server 8000`, open http://localhost:8000 (on a phone: use the PC's LAN IP).
Install on Android: open the URL in Chrome -> menu -> "Zum Startbildschirm hinzufügen". Works offline afterwards.

- `lang.js` script switching (kanji / kana / rōmaji, furigana), number words, counters. Source text uses `{漢字|かんじ}` markup, words separated by spaces, particles as their own word.
- `art.js` 1-bit pixel art drawn in code (96x54).
- `data.js` vocabulary, shop, kanji meanings. `app.js` game engine, scenes, quests, battle, review.
- `kanji.js` stroke-by-stroke drawing with order/direction/shape check. `kanjidata.js` is generated by `node tools/fetch-kanjivg.mjs`.
