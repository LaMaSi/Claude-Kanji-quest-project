# Review sheet 2: Sentence patterns and example sentences still open for review

You are a strict reviewer with two roles at once: (1) a native Japanese speaker and experienced teacher of Japanese for German-speaking beginners, and (2) a native German speaker with a good grasp of German grammar. The material below is for a beginner game (roughly JLPT N5 level) whose learners are German speakers who already know hiragana and katakana, but no kanji.

Rules for your answer:
- Do NOT simply agree. Check every single row. If you are not sure, say UNSICHER (unsure) and explain, instead of guessing.
- Report anything that is wrong, unnatural, misleading for a beginner, or inconsistent, even if it is only a small point.
- Answer ONLY with the Markdown table described below, then a short list "General remarks". No introduction.
- Verdict values: OK / FEHLER (error) / UNNATÜRLICH (correct but unnatural) / UNSICHER (unsure).
- When you propose a correction, give the exact replacement text.

## Part A – grammar notes (German text shown to learners)
Check that each explanation is correct, understandable for a beginner, and free of errors in German.

| ID | Pattern | Explanation shown to the learner |

| p_dem_wa_N | A は B です | は markiert das Thema, です schließt höflich ab. Es gibt keinen Artikel. |
| p_N_wo_kudasai | N を ください | を markiert das Objekt. 〜を ください = „〜, bitte“. |
| p_N_count_kudasai | N を 〜つ ください | Gegenstände zählt man mit ひとつ, ふたつ, みっつ …. Die Zahl steht nach を. つ ist ein allgemeiner Zähler für viele Gegenstände, aber nicht für alle Dinge und Lebewesen. |
| p_N_wo_V | N を 〜ます | Verb mit höflicher ます-Form. Das Subjekt wird oft weggelassen; im Deutschen ergänzen wir „ich“. |
| p_ni_N_ga_aru | 〜に N が あります | Ort + に + Ding + が + あります: „Es gibt …“. あります für unbelebte Dinge. |
| p_ni_N_ga_iru | 〜に N が います | Wie あります, aber für Lebewesen. |
| p_N_ga_kowai | N が こわいです | Angst haben vor: Das, wovor man Angst hat, steht mit が. |
| p_N_wo_miru | N を みます | 見ます: sehen. |
